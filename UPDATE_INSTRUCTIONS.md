# Обновление RPG Manager

1. Остановите запущенный сервер в терминале VS Code сочетанием `Ctrl+C`.
2. Сделайте резервную копию текущей папки `F:\rpg_manager_starter`.
3. Распакуйте архив. Откройте папку `rpg_manager_starter` внутри архива и скопируйте её содержимое в вашу существующую `F:\rpg_manager_starter`, подтвердив замену файлов `app.py`, файлов в `templates` и `static/style.css`.
4. Не удаляйте `.venv` — это ваше виртуальное окружение. Если в папке `instance` уже есть `rpg_manager.sqlite3`, не заменяйте и не удаляйте его: там могут храниться ваши данные. В исходном стартовом каркасе базы ещё не было; новая база создастся при первом запуске.
5. Откройте терминал VS Code в папке проекта и активируйте окружение:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

6. Установите или обновите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

7. Запустите приложение:

   ```powershell
   python app.py
   ```

8. Откройте http://127.0.0.1:5000 в браузере.

Если что-то пойдёт не так, остановите сервер и восстановите резервную копию.
