# RPG Manager — библиотека шаблонов и карточки NPC

Локальное веб-приложение на Python + Flask. База данных SQLite создаётся автоматически при первом запуске в `instance/rpg_manager.sqlite3`. Игровые данные и изменённая инструкция для ИИ сохраняются в этой базе.

## Запуск в Windows через VS Code

1. Распакуйте папку `rpg_manager_starter` и откройте её в VS Code.
2. Откройте терминал VS Code.
3. Создайте виртуальное окружение (если его ещё нет):

   ```powershell
   python -m venv .venv
   ```

4. Активируйте его:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

5. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

6. Запустите приложение:

   ```powershell
   python app.py
   ```

7. Откройте в браузере http://127.0.0.1:5000

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Что реализовано

- Библиотека шаблонов карточек NPC с базовым шаблоном.
- Создание пустого шаблона, импорт JSON с проверкой структуры и экспорт шаблона в JSON.
- Редактирование названия, описания, полей и текстовых разделов в веб-интерфейсе.
- Поддержка типов полей: короткий текст, многострочный текст, число, дата, один вариант, несколько вариантов и да/нет.
- Копирование и удаление пользовательских шаблонов. Базовый шаблон защищён от удаления.
- Редактируемая инструкция для ИИ, сохранение изменений и восстановление исходного текста.
- Создание игр/сеттингов и подключение к ним шаблонов из библиотеки.
- Поле «Дата мира» можно обновлять для существующей игры. Возраст пересчитывается автоматически для карточек, где поля в шаблоне помечены назначениями `birth_date` и `age`. Поддерживаются даты `ГГГГ`, `ГГГГ-ММ-ДД` и `ДД.ММ.ГГГГ`; для даты мира также доступен формат `ГГГГ-ММ`.
- При подключении в игру сохраняется отдельная копия структуры шаблона: последующие изменения в библиотеке не перезаписывают структуру уже подключённой игры.
- Создание, просмотр, изменение и удаление карточек NPC на основе подключённых к игре шаблонов.
- SQLite и автоматическое создание таблиц при первом запуске.

## Работа с шаблоном через ИИ

1. Откройте «Инструкция для ИИ» и скопируйте текст.
2. Передайте его ИИ вместе с описанием нужной карточки и требованиями к полям.
3. Скопируйте возвращённый JSON.
4. Откройте «Шаблоны карточек» → «Новый шаблон» → вставьте JSON и нажмите «Проверить и создать».
5. Проверьте поля в редакторе и сохраните шаблон.
6. Откройте или создайте игру и подключите сохранённый шаблон.

При импорте можно вставлять как чистый JSON, так и JSON, окружённый Markdown-ограждениями (три обратных апострофа с пометкой json).

## Где хранятся данные

По умолчанию база находится в `instance/rpg_manager.sqlite3` внутри папки проекта. Не удаляйте этот файл, если хотите сохранить свои шаблоны, игры и карточки. Для резервной копии остановите сервер и скопируйте файл базы данных в безопасное место.

Если база пока не создана, она появится автоматически при запуске `app.py`.

## Примечания текущей версии

- Приложение предназначено для локального использования на вашем компьютере; в нём пока нет авторизации и сетевого режима.
- Удаление пользовательского шаблона из библиотеки не изменяет копии структуры, уже подключённые к играм.
- Автоматическое обновление возраста срабатывает только при явных назначениях полей `birth_date` и `age`. При изменении структуры шаблона новые поля у старых карточек будут пустыми, пока карточка не будет сохранена с этими значениями.
- Разделы событий, проектов, лора, общего конструктора промпта и истории игры пока остаются заглушками.
